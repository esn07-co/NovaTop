# NovaTop demo storefront

## Run locally

1. Install [Node.js](https://nodejs.org/) 18 or newer.
2. Open a terminal in this project folder.
3. Run `node server.js` (or `npm start`).
4. Visit http://localhost:5173 in your browser.

This is a front-end demo only. Its checkout, wallet, player verification, order tracking, and support form are simulated; it does not process payments or store submitted data.
